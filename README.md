# CODO has been renamed CODION

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24103509.svg)](https://doi.org/10.5281/zenodo.24103509)

This repository holds CODO v1.0.0, the first release of the ontology now published as **CODION: Cognitive Operations, Disinformation and Influence Ontology**.

It was renamed before publication to avoid confusion with an unrelated COVID-19 ontology of the same name. The content is identical; only the name, the prefix (`dis:` became `codion:`) and the identifiers (`https://ontology.cogops.eu/codo#` became `https://ontology.cogops.eu/codion#`) changed.

**Please use CODION:**

- Repository: https://github.com/ESIcenter/codion-ontology
- Zenodo: https://doi.org/10.5281/zenodo.24103509

This repository is archived and no longer maintained. The archived CODO release remains available at https://doi.org/10.5281/zenodo.24086889.
